A Miniature World Tree is a [World Tree](machine:WorldTreeNursery) that never grows up: it starts
as a young (stage 2) tree and stays one. It uses 10,000 nutrients/s, raised by Factory Efficiency,
and grows only [World Tree Leaves](item:WorldTreeLeaf), each costing 30,000 nutrients: a leaf every
3 seconds at base speed, and never a [World Tree Core](item:WorldTreeCore).

Like a World Tree, it takes any fertilizer just to fill its store of nutrients: the fertilizer
doesn't set its speed.
