The game keeps these out of sight. Its Item Catalog doesn't list them, and it calls the first
five tiers all **Refined Sand**, telling them apart only by their icons. Its description only
hints that refining it again might change something.

Each tier is a different item. A [Refiner](machine:Refiner) turns 2 of one tier into 1 of the
next in 3 seconds, and each tier is worth twice the one before. The Reference names each tier
after how often its sand has been refined:

1. [Sand](item:Sand) refines into **Refined Sand**,
2. which refines into **Twice Refined Sand**,
3. then **Thrice Refined Sand**,
4. **Quadruply Refined Sand**,
5. **Quintuply Refined Sand**,
6. and last **Fully Refined Sand**, which the game names itself.

Each step halves the count, so one Fully Refined Sand takes 64 Sand. Refining it once more makes
something else entirely: see what it's used in, below.
